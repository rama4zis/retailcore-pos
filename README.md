# RetailCore POS

RetailCore POS is a point-of-sale system for small retail stores.

## Planned Tech Stack

- Backend: Java 25, Spring Boot 4, Spring Security, JWT, Spring Data JPA
- Database: PostgreSQL
- Frontend: React + Tailwind CSS
- Testing: JUnit 5, Mockito, Testcontainers
- API Docs: Swagger/OpenAPI
- Deployment: Docker Compose

## Core Features

- User authentication and role-based access: Admin, Manager, Cashier
- Product and category management
- Inventory tracking with stock movement history
- Sales checkout flow
- Cash/card payment tracking
- Receipt generation
- Daily and monthly sales reports
- Low-stock alerts

## MVP Build Order

1. Product and category CRUD
2. Authentication and roles
3. Inventory stock movements
4. Sales checkout
5. Payments and receipts
6. Reports dashboard
7. Dockerized deployment
