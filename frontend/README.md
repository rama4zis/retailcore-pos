# RetailCore POS Frontend

React + Vite + TypeScript frontend scaffold for RetailCore POS.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- Axios
- TanStack Query

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

Feature routes, auth, API client wiring, and pages are intentionally deferred to later frontend checkpoints.
